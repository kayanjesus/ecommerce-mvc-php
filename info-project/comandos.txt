Instalação:
Win+R->cmd        -> composer global require laravel/installer
WinPowerShell-ADM -> Set-ExecutionPolicy RemoteSigned
cmd-Raiz Project  -> composer update
cmd-Raiz Project  -> npm install
npm install laravel-echo pusher-js
npm audit fix
--------------------------------------------------------------

Rodar para o projeto funcionar:
Rodar Projeto -> php artisan serve
Rodar Projeto -> npm run dev
Criar Banco   -> php artisan migrate
Imgs Aparecer -> php artisan storage:link
Tunel Net     -> ngrok http 8000 (linkar com a sua conta ngrok)
Notificações  -> php artisan queue:work (Desnecessario)

--------------------------------------------------------------

Depois de criar o banco:
Cores Banco -> php artisan db:seed
