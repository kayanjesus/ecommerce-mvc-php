📌 SOBRE O PROJETO
----------------------------------------------------------------------
Este projeto consiste em um sistema de E-Commerce de Roupas Infantais 
desenvolvido como Trabalho de Conclusão de Curso (TCC). O sistema 
permite o gerenciamento completo de produtos, usuários e pedidos, 
além de simular pagamentos através da integração com a API do 
PagSeguro em ambiente de desenvolvimento (Sandbox).

O objetivo principal foi aplicar na prática conceitos de desenvolvimento 
web, arquitetura MVC, modelagem de banco de dados e integração com 
APIs de pagamento em um cenário real de e-commerce.

🚀 FUNCIONALIDADES DO SISTEMA
----------------------------------------------------------------------

O sistema segue a arquitetura MVC (Model-View-Controller) do Laravel:

┌─────────────────────────────────────────────────────┐
│                   Navegador do Cliente               │
└─────────────────────┬───────────────────────────────┘
                      │ Requisição HTTP
                      ▼
┌─────────────────────────────────────────────────────┐
│                   Routes (web.php)                   │
│         Define URLs e mapeia para Controllers        │
└─────────────────────┬───────────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────────────┐
│                    Controller                        │
│    Processa requisições, validações e lógica        │
└──────────────┬──────────────────┬───────────────────┘
               │                  │
               ▼                  ▼
┌──────────────────────┐  ┌──────────────────────┐
│       Model          │  │        View          │
│  Consultas banco     │  │  Templates UI        │
│  Regras de negócio   │  │  (Arquivos Blade)    │
└──────────────────────┘  └──────────────────────┘

🗄️ BANCO DE DADOS
----------------------------------------------------------------------
TABELAS PRINCIPAIS:
- users            : Contas de clientes e administradores
- products         : Catálogo de produtos
- categories       : Categorias dos produtos
- orders           : Cabeçalhos dos pedidos
- order_items      : Itens individuais por pedido
- payments         : Registros de transações de pagamento

DIAGRAMA DE RELACIONAMENTOS:
users (1) ------- (n) orders
orders (1) ------ (n) order_items
order_items (n) - (1) products
products (n) ---- (1) categories
orders (1) ------ (1) payments

RELACIONAMENTOS DETALHADOS:
- Usuário -> Pedidos: Um-para-Muitos
- Pedido -> Itens do Pedido: Um-para-Muitos
- Item do Pedido -> Produto: Muitos-para-Um
- Produto -> Categoria: Muitos-para-Um
- Pedido -> Pagamento: Um-para-Um

💳 INTEGRAÇÃO COM PAGSEGURO
----------------------------------------------------------------------
O sistema integra com a API do PagSeguro em modo Sandbox.

FLUXO DE PAGAMENTO:
Usuário -> Sistema -> PagSeguro API -> Ngrok Tunnel -> Webhook

POR QUE USAR NGROK?
Como o PagSeguro requer uma URL pública para enviar notificações de 
pagamento (webhooks), o Ngrok foi utilizado para expor o servidor 
Laravel local (porta 8000) para a internet.

PROCESSO DE PAGAMENTO:
1. Usuário adiciona produtos ao carrinho e vai para o checkout.
2. Sistema envia dados de pagamento para API do PagSeguro.
3. PagSeguro redireciona para página de pagamento simulada.
4. Usuário completa pagamento no ambiente Sandbox.
5. PagSeguro envia notificação POST para a URL pública do Ngrok.
6. Sistema atualiza status do pedido no banco de dados.
7. Usuário recebe confirmação.

⚙️ INSTALAÇÃO E CONFIGURAÇÃO
----------------------------------------------------------------------
1. Clonar o Repositório: git clone [URL]
2. Instalar Dependências PHP: composer install
3. Instalar Dependências Frontend: npm install
4. Configurar Ambiente: cp .env.example .env && php artisan key:generate

[CONFIGURAÇÃO .env]
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=nome_do_banco
DB_USERNAME=seu_usuario
DB_PASSWORD=sua_senha

PAGSEGURO_EMAIL=seu_email_sandbox
PAGSEGURO_TOKEN=seu_token_sandbox
PAGSEGURO_SANDBOX=true

5. Executar Migrations: php artisan migrate
6. Compilar Assets Frontend: npm run dev (ou npm run build)
7. Iniciar Servidor Laravel: php artisan serve
8. Iniciar Ngrok: ngrok http 8000
